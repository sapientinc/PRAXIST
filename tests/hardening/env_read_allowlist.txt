# Allowlist of env-var reads under praxist/{core,plugins,infrastructure}.
#
# Format:   <path>::<var_name>  [# optional reason]
# Comments and blank lines are ignored. ``<dynamic>`` is the sentinel
# the audit uses when the env-var name isn't a string literal.
#
# Discipline: core domain code does NOT read env vars; reads happen at
# boundaries (CLI entrypoints, subprocess env construction, MCP stdio
# subprocesses). New code that needs an env value must either route it
# through ``RunConfig`` or earn an explicit entry here, with reason.
#
# Every entry names a current process or adapter boundary. Remove an entry when
# its owner stops reading that value directly.
